# WPS 连接页与 ChatGPT 对话操作：12 项迭代

本次按 [ChatGPT Google Drive 连接与使用说明](https://help.openai.com/en/articles/10929079-google-workspace-admin-managed-setup) 对照：先连接个人账号，再在对话中提出操作，结果返回原云文件。WPS 仍使用其个人 SkillHub 授权协议。

| 序号 | 具体改进 | 验收点 |
| --- | --- | --- |
| 1 | 登录后首页只呈现授权卡片 | 首页不出现工具目录和 JSON 编辑器 |
| 2 | 未登录首页只有 ChatGPT 登录入口 | 不展示无法使用的云操作 |
| 3 | 顶部只保留产品名和私有连接提示 | 授权入口清晰 |
| 4 | 缩小连接卡和页面宽度 | 桌面与窄屏均能直接看到状态 |
| 5 | 已连接时只显示状态与断开入口 | 无需手动再点验证 |
| 6 | 新授权完成后自动只读验证 | 状态来自 WPS 业务读取结果 |
| 7 | 已保存但未验证的连接只自动验证一次 | 避免反复请求 WPS |
| 8 | 等待授权时保留官方授权链接和取消入口 | 页面刷新后可继续本次授权 |
| 9 | 简洁页隐藏诊断、时间戳和手动令牌输入 | 常用流程不要求理解技术细节 |
| 10 | 断开连接保留明确确认 | 只删除本站凭据，不删除 WPS 文件 |
| 11 | 移除额外工作台页面 | 网站只保留授权入口，文档操作通过 ChatGPT 工具完成 |
| 12 | MCP 指引要求直接调用工具并返回云文件链接、写后读回 | 用户在 ChatGPT 对话中完成文档任务 |

限制：WPS 个人 SkillHub 与 Google Drive 的账号协议、工具范围和编辑能力不同。页面简化不会改变 WPS 账号权益；619 项目录不是 619 项当前账号全部验收通过。本文的视觉检查、自动化回归和生产部署结果应在发布后补记，不以代码存在代替验收。
