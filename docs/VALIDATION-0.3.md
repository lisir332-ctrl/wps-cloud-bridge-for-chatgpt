## 账号验证的具体修正

原 0.1 线上授权轮询的 502 已定位至 workerd 不支持 `redirect:error`。0.2 改为 manual 并拒绝重定向，线上无账号的授权等待探测已恢复 HTTP 200。

0.3 不以匿名工具目录或任意成功调用来更新账号验证状态。显式验证必须取得成功业务码和可识别的 `data.items` 列表；合法空列表及省略辅助分页字段的末页可通过。只有官方默认盘解析错误 400001 且明确建议 search_files 时，才执行一次固定、不含用户数据的只读搜索；401、403、429、超时和未知错误不会回退。

## 四套真实账号验收的通过条件

- 文档：创建独立 DOCX、核对原文、精确修改一段、读回新段落，并核对保护段落与旧内容消失。
- 表格：创建独立 XLSX、读取真实工作表 ID、核对初始区域、写入公式，并同时核对公式表达式、计算结果和相邻单元格。
- 演示：创建独立 PPTX、取得真实页 ID 与文本框 ID、核对文本框和文字、确认页面存在。
- 问卷：创建未发布草稿、读回 ID/标题/题型/选项，确认仍为 Draft；不自动发布或收集真人回答。

只有实际报告中已完成的检查计为通过。视觉、导出、问卷发布等 skipped 检查保持未检查状态。历史报告携带 connectionCurrent；旧连接的报告不能证明新连接可用。

## 代码生成 PPT 的完成判据

生成标准可编辑 PPTX 后，调用官方 upload_new_file 新建云文件，从 data.id 取得文件编号；read_file 使用 KDC 格式核对页数及逐页文字。遇到 pending 保留 task_id，使用只读续验继续查询原文件，不再上传。同请求编号原子去重；结果不确定时保留已有文件 ID 和状态。

这一制作器目前提供固定 16:9 的文字演示，1–12 页、两套主题。图表、复杂母版、动画等并未被这份固定提纲制作器覆盖；目录中的其他演示工具仍受官方接口与账号条件约束。
