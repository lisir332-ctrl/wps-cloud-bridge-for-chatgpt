# WPS 云文档助手 0.3.1 验证记录

日期：2026-10-22。此版本延续 0.3.0 的 ChatGPT 自定义 MCP 与 WPS 个人云账号连接，不增加桌面或本地文件处理路径。

## 连接恢复

- WPS 连接凭据保存在站点 D1 中，按 ChatGPT 注入的用户标识隔离，并以 AES-GCM 加密；刷新页面和重启 ChatGPT 不会主动删除该记录。
- 页面初次读取状态时，对临时服务失败或尚未注入的 `SIGN_IN_REQUIRED` 做最多 3 次短重试。仍未取得 ChatGPT 用户身份时，不把状态描述为 WPS 断开；切回页面或窗口恢复可见时再读一次。
- 成功重新读到状态后，只清除状态读取本身留下的错误。验证连接等实际业务错误仍会显示。
- 连接有效期使用 WPS 个人 SkillHub 授权交换响应中的 `expires_in`。当前公开资料没有确认个人 SkillHub 刷新令牌接口；到期后仍需通过官方个人授权页重新连接，不宣称永久有效。
- WPS 授权页面完成自身回调后，ChatGPT 页面使用已保存的短期授权尝试继续轮询；回到 ChatGPT 页面或窗口聚焦时会补查状态。授权码和 WPS 令牌不会写入浏览器存储。

## 云端能力边界

- 用户通过 ChatGPT 的私有连接器登录，分别授权自己的 WPS 个人账号；文档读写由托管服务调用 WPS SkillHub 云端 MCP。
- WPS 桌面 JS 宏编辑器是客户端宏环境，官方资料说明其 JavaScript 运行时是 V8 而非浏览器；它不等于云端 SkillHub 执行接口。
- 个人版宏/VBA能力因版本和订阅而异，官方帮助资料说明免费个人版默认不含 VBA 宏运行环境。连接器不执行任意 JavaScript 或 VBA。
- ChatGPT 中的代码驱动操作使用受限 JSON 工作流：先校验工具、参数和风险，再按顺序调用官方云端工具，并保存唯一 request ID；不支持把用户代码当作 shell 或宏执行。
